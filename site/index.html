QUY TRÌNH

Từ file export đến request có thể kiểm tra, trong bốn bước.

Plugin giúp bạn chuyển cấu trúc collection và giữ đường truy vết về nguồn. Bạn quyết định cách chạy sau khi xem báo cáo.

01

Chọn đầu vào

Chọn collection .json v2.0/v2.1, environment và globals nếu có. Collection v2.0 được chuẩn hóa trong bộ nhớ; file gốc giữ nguyên.

02

Analyze

Xem request chuyển được, blocker, script và đồ thị biến giữa các request. Bước này không gọi API.

03

Chọn chiến lược

Giữ nguyên thứ tự, tự tách request độc lập hoặc chỉ xuất báo cáo. Preview giải thích vì sao một request cần chạy theo chuỗi.

04

Export & xác minh

Chạy scenario.http từ đầu file; các request trong independent.http có thể chạy riêng. So sánh kết quả khi cần độ tương đương runtime.

KHẢ NĂNG

Chuyển đổi có trách nhiệm, đủ ngữ cảnh để tiếp tục công việc.

↗

Không ép mọi request thành một chuỗi

Đồ thị phụ thuộc tách request độc lập khỏi các bước cần dữ liệu từ request trước. Bạn có thể chọn giữ nguyên thứ tự hoặc chỉ tạo report.

◈

Environment và script

Chuyển scope biến và các API pm.* có ánh xạ đã kiểm thử. Giá trị nhạy cảm nằm trong private environment, được thêm vào .gitignore.

⌘

Không bỏ qua phần khó

GraphQL, gRPC, WebSocket chỉ được xuất khi metadata cần thiết đầy đủ. Request chưa bảo toàn semantics đi vào manual-review.md cùng vị trí trong nguồn.

◎

Đối chiếu sau migration

Adapter Newman và IntelliJ trace tạo báo cáo so sánh method, URL, header, body, status và assertion; dữ liệu nhạy cảm được che bằng fingerprint.

▣

Điều khiển trong IDE

Mở Tools → Postman Migration Assistant hoặc nhấn Ctrl+Alt+Shift+P. Preview, dependency graph, output và report nằm trong một quy trình.

◇

Phân tích offline

Đọc, phân tích và xuất file trên máy. Không gọi Postman, JetBrains hay máy chủ của nhà phát triển trong luồng import.

Ranh giới rõ ràng

Script JavaScript ngoài tập được hỗ trợ, hành vi mạng/async phức tạp và metadata protocol thiếu có thể cần sửa thủ công. Tình trạng “convertible” không chứng minh request đã chạy đúng với API của bạn. Compatibility hiện được công bố cho target ghi trong matrix ↗.

BẮT ĐẦU

Thử trên một collection thực của bạn.

Technical preview nhắm IntelliJ IDEA Ultimate 2025.3.2. Liên hệ để tham gia beta, nhận bản build và hướng dẫn cài bằng Settings → Plugins → Install Plugin from Disk.

Yêu cầu bản beta ↗
  1. Export collection và environment từ Postman.
  2. Mở project trong IntelliJ IDEA; vào Tools → Postman Migration Assistant.
  3. Chọn file, nhấn Analyze, đọc blocker và chọn chiến lược xuất.
  4. Chạy file .http phù hợp, xác minh phản hồi và assertion.

CÂU HỎI THƯỜNG GẶP

Câu trả lời ngắn, đủ để quyết định.

Plugin này làm gì?

Postman Migration Assistant phân tích Postman Collection v2.0/v2.1 và xuất request cho IntelliJ HTTP Client cùng environment, script tương thích, source map và báo cáo những phần cần rà soát.

Tôi có cần export collection v2.1 lại từ Postman không?

Không. Plugin nhận v2.0 hoặc v2.1; v2.0 được chuẩn hóa trong bộ nhớ và file gốc không bị sửa.

Vì sao một số request phải chạy từ đầu file?

Request trong scenario.http có thể dùng token, ID hoặc biến do request trước tạo. Chạy chúng theo thứ tự. Request trong independent.http có thể chạy riêng hoặc song song.

97,2% có nghĩa là 97,2% request chạy thành công?

Không. Đây là tỷ lệ chuyển đổi tĩnh của 2.510 trong 2.582 request thực thi thuộc 20 collection công khai. Cần kiểm thử runtime trên API đích để xác nhận hành vi.

Dữ liệu collection có được tải lên máy chủ không?

Không trong luồng import. Phân tích và xuất file diễn ra cục bộ. Khi bạn tự chạy file .http, IntelliJ HTTP Client gửi request đến API mà bạn cấu hình.

Plugin có hỗ trợ GraphQL, gRPC và WebSocket không?

Có điều kiện. GraphQL cần query; gRPC cần URL, service/method và message; WebSocket cần URL và message sequence. Thiếu dữ liệu cần thiết thì request được chỉ định rà soát thủ công.

Hiện dùng trên IDE nào?

Technical preview được nhắm tới IntelliJ IDEA Ultimate 2025.3.2 (build IU-253.30387.90). Xem compatibility matrix để biết bằng chứng kiểm thử mới nhất. Chưa có công bố hỗ trợ rộng cho các phiên bản hoặc hệ điều hành khác.
